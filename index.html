Ferrite data

Channel data for Ferrite Console: licensed radio sites, airport frequencies and amateur repeaters near a place, split by grid square so an app only downloads what's around it, and the amateur satellites a handheld can work. Built 2026-11-07.

How it's organized

  • index.json: every source, with its build date, row count, licence and its zip's size and SHA-256.
  • <source>/index.json: one source's tiles and their row counts, plus format and level.
  • Tiles are Maidenhead grid locators: 4-character squares such as tafl/CN89.json (2° by 1°). A busy square (over 6,000 rows: big cities) comes as its 6-character subsquares instead (tafl/CN89kg.json), listed under split. Airports and repeaters use 2-character fields (airports/CN.json, 20° by 10°).
  • satellites/sats.json: not tiles, one small file: each satellite's orbit elements and FM or APRS transponders (satellites-1, in the repository's README).
  • <source>.zip: the whole source in one download, for keeping it offline.
  • stats.csv: a line per source each time it's built (row count, rows added and removed, and for repeaters HearHam's own counts), kept from build to build.
  • Tiles are columnar JSON (columnar-1): names once, then whole-number differences for position and frequency. The format is in the repository's README.

Updates

Rebuilt daily from each source's own public download: HearHam, OurAirports, CelesTrak and SatNOGS every day, the TAFL and the FCC when they publish new files. A source that can't be fetched keeps its last copy.
