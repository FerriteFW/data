# Airport data licence

- Source: OurAirports, https://ourairports.com/data/ (files from https://davidmegginson.github.io/ourairports-data/: `airports.csv`, `airport-frequencies.csv`).
- Licence: public domain. OurAirports' data page: "All data is released to the Public Domain".
- No attribution is required; we credit OurAirports anyway:

  > Airport data from OurAirports (ourairports.com), public domain.

- Changes: Ferrite keeps open airports' 108-137 MHz frequencies, names each airport by its ICAO code (else its GPS or local code), rounds coordinates to 5 decimals and splits the rows into 2-character Maidenhead fields.
- OurAirports' data comes with no guarantee of accuracy; never use it for navigation.
